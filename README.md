# 🌦️ Rainfall Prediction Classifier

This notebook is a final project focused on building a machine learning pipeline to predict whether it will rain tomorrow based on historical weather data from Australian cities.

## 📌 Project Overview

- **Goal**: Build a binary classification model to predict `RainTomorrow` (Yes/No).
- **Dataset**: Australian Bureau of Meteorology (via [Kaggle](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package)).
- **Tech Stack**: Python, pandas, scikit-learn, seaborn, matplotlib

## ✅ Key Objectives

- Perform feature engineering on real-world weather data
- Create and optimize classification pipelines (Logistic Regression, Random Forest)
- Apply grid search with cross-validation
- Visualize performance metrics (confusion matrix, classification report)

## 📂 Dataset Fields

Features include:
- Temperature (Min/Max/9am/3pm)
- Rainfall, Evaporation, Sunshine
- Wind Direction & Speed
- Humidity, Pressure, Cloud cover
- Target: `RainTomorrow` (Yes/No)
